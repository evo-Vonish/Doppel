# Doppel（替身 Tishen）

> 替身已启动，目标无所遁形。

本地优先的算法浏览器：每个替身是按规格烘焙的容器沙盒身份（时区/locale/字体/GPU/Chrome 指纹全自洽），网站只能看到一套干净的 Linux 桌面分身数据；旁路观测 + 页面探针全量记录网页行为，三层判别引擎对追踪、指纹与挖矿脚本分级告警，证据链完整。
